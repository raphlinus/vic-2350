# Vic Sans font

The Vic Sans font is custom designed for this project. Font sources are in [Bits'N'Picas] format. Use tools/kbitx2font.py to convert from this format into binary form.

The kerning data for the font is in vic-sans-14.kern, a separate file.

![A showing of the font](vic-sans-14.png)

[Bits'N'Picas]: https://github.com/kreativekorp/bitsnpicas
