# Tileset and tilemap for alien colony

This is a demo image to show off tile rendering capabilities. The tileset consists of 16x16 pixel tiles, each with no more than 16 colors. The tileset image is alien_world.png, and there is additional metadata in [Tiled] format. A very simple map is in colony.tmx. The [tools/tiles.py](../tools/tiles.py) script converts this into binary form suitable for rendering in vic-2350.

The tile artwork is by [Dandelion Pixel Art].

[Tiled]: https://www.mapeditor.org/
[Dandelion Pixel Art]: https://linktr.ee/dandelion.pixelart
